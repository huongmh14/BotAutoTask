# Thuật ngữ miền (Ubiquitous Language) — BotAutoTask

> Nguồn sự thật về thuật ngữ (`C08`). Dùng thống nhất trong mọi spec, thiết kế, comment và tên biến/class.

| Thuật ngữ | Định nghĩa | Không gọi là | Tên trong code / schema |
|---|---|---|---|
| **Goal** | Mục tiêu công việc do người dùng giao, có tiêu đề, prompt đích, lệnh kiểm chứng (`acceptance_cmd`), chạy qua một hoặc nhiều bước cho tới khi đạt điều kiện dừng. | Task rời, Job, Ticket | `goals` (D1), `goal` (`orchestrator.js`) |
| **Step / StepReceipt** | Một lượt thực thi nguyên tử của một AI Core trong quá trình giải quyết Goal, kết thúc bằng biên nhận kết quả (`outcome`, `summary`, `harnessId`, `modelId`, `git_commit`). | Turn lẻ, Sub-task, Log line | `StepReceipt` (`src/core/types.js`), `journal_entries` (D1) |
| **Harness** | Bộ chuyển đổi (adapter) chuẩn hoá giao tiếp giữa bộ điều phối và một công cụ/CLI AI cụ thể (`checkHealth`, `discoverModels`, `executeStep`). | Provider, Wrapper, Plugin | `AgentHarness`, `HarnessRegistry` (`src/core/harness-registry.js`, `src/harnesses/`) |
| **Core** | Công cụ hoặc nền tảng AI thực thi phía dưới một Harness (`opencode`, `antigravity`, `claude-codex`, `neko-core`, `custom-cmd`). | Engine, Bot, LLM | `preferredCore`, `core_used` |
| **FreeModelRanker** | Bộ quét động và chấm điểm xếp hạng các model miễn phí/rảnh dựa trên pattern ưu tiên, `opencode models`, OpenRouter catalog và bảng cooldown. | Model selector, Router | `FreeModelRanker` (`src/core/model-discovery.js`) |
| **Lease & Lease Epoch** | Quyền thực thi độc quyền một Goal có thời hạn (90 giây) trên D1, được chiếm giữ bằng câu lệnh SQL nguyên tử (CAS) kèm số thứ tự `lease_epoch` tăng dần để chặn worker cũ ghi đè (fencing). | Lock tĩnh, Session, Mutex | `lease_owner`, `lease_expires_at`, `lease_epoch` (`cloud-core/worker.js`) |
| **AgentMesh** | Mạng lưới điều phối đa agent nội bộ qua Loopback HTTP MCP Server và thẻ inline `[AGENT_TOOL_CALL]`, cho phép `lead`, `coder`, `reviewer` giao việc và bẻ lái. | Swarm, Cluster, Bus | `AgentMesh` (`src/core/agent-mesh.js`) |
| **Writer / Reader** | Hai vai trò phân quyền của subagent trong Mesh: `writer` được sửa code trong `git worktree` riêng; `reader` chỉ đọc/kiểm tra không tạo worktree. | Worker/Master, Producer/Consumer | `role: 'writer' \| 'reader'` (`src/core/agent-mesh.js`) |
| **Worktree** | Thư mục làm việc Git cô lập (`.botautotask/worktrees/<agentId>`, nhánh `botautotask/agent-<agentId>`) cấp riêng cho mỗi `writer` để sửa code song song không đè file nhau. | Clone, Sandbox folder, Submodule | `WorktreeManager` (`src/core/worktree-manager.js`) |
| **Hard-refuse Policy** | Lớp hàm thuần kiểm tra và chặn cứng các lệnh/đường dẫn phá huỷ hoặc nhạy cảm (`rm -rf /`, đọc credential, `.env`) bất kể chế độ `auto` hay `yolo`. | Prompt guardrail, Blacklist | `decide()`, `isHardRefuseCommand()` (`src/core/policy.js`) |
| **Approval Gate** | Cổng yêu cầu người dùng duyệt (ràng buộc theo mã băm `sha256(action+args)`, hết hạn 30 phút, claim nguyên tử) trước khi thực thi hành động nhạy cảm do agent yêu cầu (như `MergeAgentWorktree`). | Confirm dialog, Auth check | `proposeApproval()`, `decideApproval()` (`src/core/agent-mesh.js`, `approvals` D1) |
| **CompletionContract & Mutation Epoch** | Hợp đồng nghiệm thu chỉ-thêm (tối đa 16 tiêu chí) gắn với mã băm trạng thái diff hiện tại (`mutation_epoch`); hễ code thay đổi thì kết quả validate cũ tự động hết hiệu lực. | Test suite, Checklist tĩnh | `CompletionContract` (`src/core/completion-contract.js`) |
| **Experience Library** | Thư viện lưu các bài học đã được kiểm chứng thực tế theo bộ ba `{cue, lesson, evidence}` tại `.botautotask/library/<domain>/` để nạp vào prompt các phiên sau. | Memory, Knowledge base, RAG | `Harness2Engine` (`src/core/harness2-engine.js`) |
| **Peer Framing (Defang)** | Kỹ thuật đóng khung tin nhắn giữa các agent vào thẻ `<peer-message>` và trích dẫn `> ` mọi dòng để vô hiệu hoá tấn công Prompt Injection chéo giữa các agent. | Sanitization, Escaping | `framePeerMessage()` (`src/core/agent-mesh.js`) |
| **Arena Fan-Out** | Chế độ giao cùng một nhiệm vụ và lệnh `--check` cho 2–4 Core chạy song song trên các worktree độc lập, chấm điểm khách quan (deterministic) để chọn nhánh thắng. | Benchmark, A/B test | `SPEC-ARENA` (`docs/feature/07-orca-arena-accounts-ratchet-awake.md`) |
| **Ratchet Guard** | Bộ quét `git diff` chặn hành vi AI tự hạ chuẩn chất lượng (thêm `@ts-ignore`, `eslint-disable`, `.skip`, xoá file test) trước khi cho phép hoàn tất Goal hoặc merge. | Linter, Pre-commit | `ratchetCheck` (`SPEC-ARENA`, `CONSTRAINTS.md`) |
| **Awake Lease** | Cơ chế giữ hệ điều hành không tự chuyển sang chế độ Sleep do idle trong khi đang có ít nhất một Goal/Agent chạy (đếm tham chiếu `refcount`). | Wake timer, Keep-alive | `acquireAwake()` (`SPEC-ARENA`) |
