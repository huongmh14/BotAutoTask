# Changelog — v1.0.0 (2026-10-20)

> Phiên bản chuẩn hoá kiến trúc Pluggable Multi-Core Orchestrator, Agent Mesh v2, Safety Gate và bộ tài liệu kỹ thuật theo Base `writing-spec-for-ai v1.2.1`.

## Tính năng chính (`SPEC-CORE`, `SPEC-UI`, `SPEC-CLOUD`, `SPEC-MESH`, `SPEC-VERIFY`, `SPEC-PROVISION`, `SPEC-SAFE`)

- **Pluggable Multi-Core & Dynamic Free-Model Ranker (`SPEC-CORE`):**
  - 5 adapter tách biệt (`opencode`, `antigravity`, `claude-codex`, `neko-core`, `custom-cmd`).
  - Quét động model miễn phí, tự động ghi `StepReceipt` và trượt sang lõi/model kế tiếp khi gặp `HTTP 429` (`cooldownMs = 30m`).
  - Vòng lặp `SupervisorLoop` đọc trực tiếp `transcript.jsonl` và NDJSON stream để sinh `.botautotask/DIRECTIVE.md`.
- **Agent Mesh v2 & Git Worktree Song Song (`SPEC-MESH`, `SPEC-SAFE`):**
  - Loopback HTTP MCP Bridge (`CreateAgent`, `SendToAgent`, `DelegateParallel`, `CheckSubagent`, `MergeAgentWorktree`).
  - Mỗi `writer` chạy trên một `git worktree` cô lập; bảo vệ dữ liệu chưa commit trên nhánh chính (`MAIN_DIRTY_COLLISION`) và dùng `git reset --keep HEAD~1` khi revert.
  - Chống Prompt Injection chéo giữa các agent bằng `framePeerMessage()` (`<peer-message>`) và chống lặp bằng cửa sổ trượt 10 phút (`12 tin / 10 phút`).
- **Closed-Loop Verification, Policy & Approval Gate (`SPEC-VERIFY`, `SPEC-SAFE`):**
  - Chặn lỗi auto-pass: goal thiếu `acceptance_cmd` trả `COMPLETED_UNVERIFIED` thay vì `COMPLETED`.
  - Lớp `policy.js` hard-refuse tách biệt + Approval Gate ràng buộc theo mã băm `sha256(action+args)` cho `MergeAgentWorktree`.
  - Thư viện kinh nghiệm `Harness2Engine` (`{cue, lesson, evidence}`) tự động nạp và lưu khi `COMPLETED` (`SPEC-H2`, `SPEC-SAFE`).
- **Cloud-Core 24/7, Lease CAS & Auto-Provisioning (`SPEC-CLOUD`, `SPEC-PROVISION`):**
  - Cloudflare Worker + D1 SQLite với câu lệnh chiếm giữ Lease nguyên tử (CAS + `lease_epoch` fencing, trả `409` khi epoch cũ).
  - Xác thực Bearer fail-closed + so sánh constant-time (`isAuthorized`).
  - Tự động dựng hạ tầng Cloudflare qua `npm run cloud:setup` (`scripts/cloud-provision.mjs`).
- **Attention Web UI & Mobile PWA (`SPEC-UI`, `SPEC-SAFE`):**
  - Giao diện Tactical Coworker PWA nhúng 1 file (`src/ui/dashboard-html.js`), hỗ trợ SSE replay (`Last-Event-ID`), phân nhóm roster theo mức cần chú ý (`attention / working / done / idle`), xem diff trước khi merge và hộp lệnh nhanh `Ctrl+K`.

## Breaking Changes & Hướng dẫn nâng cấp

- Goal không có `--check` (`acceptance_cmd`) nay kết thúc ở trạng thái `COMPLETED_UNVERIFIED` thay vì `COMPLETED`. Để nhận trạng thái `COMPLETED`, truyền `--check "<lệnh test>"` khi tạo goal.
- Khi `coder` (subagent) gọi `MergeAgentWorktree`, hệ thống không còn tự động merge ngay mà tạo bản ghi `awaiting_review` trên Web UI để người dùng kiểm tra diff và bấm **Duyệt**.
